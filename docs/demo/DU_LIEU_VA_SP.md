# Dữ liệu và hợp đồng stored procedure

Tài liệu thiết kế PostgreSQL 16; chưa tạo migration/code. Tên trường mới dùng snake_case, PK bigint GENERATED BY DEFAULT AS IDENTITY (trừ UUID phiên/giao dịch); FK cùng kiểu với bảng đích. Tiền numeric(15,0), tỷ lệ numeric(5,2), thời điểm timestamptz, trạng thái text + CHECK. Không đưa CCCD/ảnh rõ vào audit/log.

## Bảng hiện hành

| Nhóm | Bảng và quan hệ |
|---|---|
| Tài khoản | TAI_KHOAN → SINH_VIEN bằng MaTaiKhoan unique; vai trò ADMIN/KETOAN/KYTHUAT/BAOVE/SINHVIEN |
| Phòng | TOA_NHA → PHONG ← LOAI_PHONG; PHONG → GIUONG; SINH_VIEN + GIUONG → DANG_KY_PHONG → LUU_TRU |
| Hóa đơn | PHONG → CHI_SO_DIEN_NUOC (unique phòng/kỳ), HOA_DON (unique phòng/kỳ) → CHI_TIET_HOA_DON, THANH_TOAN; DON_GIA_DICH_VU → chi tiết |
| Sửa chữa | PHONG/SINH_VIEN → YEU_CAU_SUA_CHUA → XUAT_VAT_TU ← VAT_TU |
| An ninh | SINH_VIEN → RA_VAO → VI_PHAM; AUDIT_LOG lưu old/new JSONB |

Không có bảng chính sách, công ích, khách thăm, outbox, hồ sơ mã hóa hoặc hợp đồng đầy đủ trong schema hiện hành. Không diễn giải ERD lịch sử là các bảng đã tồn tại.

## Bổ sung dữ liệu khi triển khai

Mọi bảng có created_at, updated_at, version integer >=1 nếu cập nhật; trạng thái terminal không sửa bằng API trực tiếp. FK dùng RESTRICT cho chứng từ tài chính/lịch sử, không cascade xóa bằng chứng. Index FK và các tổ hợp lọc trạng thái/thời gian; chỉ index JSONB khi có truy vấn cụ thể.

## SP: vào/ra và transaction

OUT thống nhất: status text, message text, id bigint/UUID nếu tạo đối tượng; API ánh xạ SUCCESS/ALREADY_DONE về 2xx, INVALID về 422, NOT_FOUND về 404, CONFLICT/EXPIRED/INSUFFICIENT_STOCK về 409. Lỗi SQL phải rollback; không suy thành công từ việc không có exception. SP không gọi mạng.
